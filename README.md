### UNIT 1 — Question 1: World Wide Web (WWW)

RGPV B.Tech CSE | 5th Semester | Internet and Web Technology

### 1\. Simple Definition

The World Wide Web (WWW) is a collection of linked web pages that we can access through the Internet using a web browser.

Real-Life Example: When you open YouTube in Google Chrome and watch a video, you are using the World Wide Web.

### 2\. 10 Important Points

* WWW stands for World Wide Web.

* It works on the Internet.

* It contains web pages and websites.

* Web pages are connected through hyperlinks.

* Every web page can have a URL.

* It uses HTTP and HTTPS protocols.

* We use web browsers to access the WWW.

* Web servers provide web pages to users.

* It supports text, images, audio and video.

* It is used for education, communication and entertainment.

### 4\. Working of WWW

* The user opens a web browser.

* The user enters a website address (URL).

* The browser finds the server's IP address using DNS, if needed.

* The browser sends an HTTP or HTTPS request.

* The web server receives the request.

* The server processes the request.

* The server sends a response to the browser.

* The browser displays the web page to the user.

Real-Life Example: When you open `www.google.com`, your browser requests the Google web page, receives the response and displays it on your screen.

### 5\. Advantages of WWW

* Provides information quickly.

* Supports online education.

* Makes communication easy.

* Provides online shopping.

* Offers entertainment.

* Supports online banking.

* Allows information sharing.

* Connects people worldwide.

### 6\. Disadvantages of WWW

* Some information may be incorrect.

* Online fraud can happen.

* Personal data may be misused.

* It can waste time.

* Harmful content may be available.

* Internet access is required.

* Malicious links can cause security problems.

* Excessive use can affect productivity.
